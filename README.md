# Splunk Mastery

A modern SOC analyst learning platform focused on Splunk, Search Processing Language (SPL), Threat Hunting, Detection Engineering, Windows Event IDs, and MITRE ATT&CK fundamentals.

## Features

- Modern dashboard-style UI
- Dark cyberpunk design
- SPL learning path
- Threat Hunting notes
- Detection Engineering concepts
- MITRE ATT&CK integration
- Windows Event ID references
- Responsive layout
- Beginner-friendly explanations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Google Fonts

## Installation

Clone the repository:

```bash
git clone https://github.com/lakshaysharma2805/Splunk-Notes.git
```

Open the project directory:

```bash
cd splunk-mastery
```

Run locally by opening:

```bash
index.html
```
